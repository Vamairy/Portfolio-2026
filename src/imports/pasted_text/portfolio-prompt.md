PROJECT LAYOUT

I like the idea of several projects being visible simultaneously on desktop.

Explore a composition inspired by an editorial gallery rather than a conventional portfolio grid.

Projects can sit next to each other in a continuous horizontal visual composition, similar to a curated exhibition of work.

They should NOT overlap and should NOT be rotated.

Avoid making them feel like generic identical cards. Use consistent visual rules, but allow each project to have its own art direction, imagery and subtle color atmosphere.

On large desktop screens, approximately 4–5 projects can be partially or fully visible depending on the composition.

It is okay if the gallery extends beyond the viewport and encourages horizontal exploration, as long as usability remains obvious.

Feel free to propose a more interesting arrangement if it preserves:
clarity, visual rhythm, quick scanning and easy access to each case study.

RESPONSIVE BEHAVIOR

- Make navigation and interaction obvious.
